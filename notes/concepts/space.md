---
title: Space selection
kind: variable · hypothesized router
---
The mechanism that decides which content source the output draws on: the model's own view (Belief), a scoped proposition (Scoped belief), or the audience's (User's belief), and whether the result is asserted or framed. Comprehension work finds a shared value slot plus a routing subspace that selects the space to read out (Steele, Wen & Han 2026); earlier drafts of this map called the function "commitment".

**In an LLM.** Writing a story, the model keeps "Paris is in France" intact and generates from a space in which the captain believes otherwise. Answering a geography question, it generates from its own space.

**How to test.** Take the router subspace from the mental-spaces work and measure its loading across cases with the proposition held fixed. Then steer it while holding content fixed and check whether the output's frame changes. Shown only for comprehension so far; whether generation uses the same router, and whether an instructed lie uses it at all, are open.
