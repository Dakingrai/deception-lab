Claim A. There is an internal answer variable that causally influences both honest and dishonest responses. Claim B, that the variable is a belief representation, is not tested here. HYPOTHESIS Every bar and curve below is a prediction derived from a hypothesis. None are measurements.

The runs

Which cells can separate the hypotheses

At late layers the last token may already hold the output, so a patch can move the answer by copying it. Answer-variable transfer and output copying make the same prediction in some cells and opposite predictions in others. Only cells where they differ count as evidence for Claim A.

Step 1 · find the layer

Patch the full last-token vector, layer by layer

The sweep across layers

Procedure

  1. Build items so all prompts end in the same answer prefix. Rotate which letter holds each answer, and keep pairs whose source and target letters differ.
  2. Validate the lie instruction before patching. Check its tokenization, and check behaviourally that the model produces false answers competently. Prepare two or three instruction styles (an explicit lie to a user, "pick an incorrect option", one goal-framed version), since "false option" may be read as a selection task rather than lying.
  3. Run P1–P4 and the same-letter control. Cache the residual stream at every layer and position.
  4. For each layer, copy the source's last-token residual into the target in all four source × target cells and the control. Record the full A–D distribution at the answer token.
  5. Score every patched distribution against each prediction (no change, answer variable, output copy, disruption) by Jensen–Shannon similarity. Build the predictions from measured runs: copy = the source's measured output; exclusion = the target's lie behaviour with the forbidden letter moved, using position bias from the inverted items.
  6. Read the cells by role: honest → lie is the primary test, lie → honest supports it, honest → honest is the positive control, and lie → lie counts only where the source's lies are peaked.
  7. Controls at the candidate layers: the same-letter source should change nothing; compare matched- and unmatched-length pairs and different letter assignments; repeat the primary test under each instruction style.
  8. If the last token shows nothing clean, patch at other positions aligned by semantic role (the final token of each entity name, comparing the first token for multi-token names), never by raw index.
Step 2 · find the subspace

Isolate the variable inside the chosen layer

The full residual carries more than the answer. Distributed alignment search learns a rotation R of the residual at layer ℓ* and patches only the first k rotated dimensions from source to target; the rest stays from the target run.
